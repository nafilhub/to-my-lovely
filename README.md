# 🌸 To My Lovely - Special Romantic Gift Web

Aplikasi web kado ucapan berbasis **React + Vite** yang dirancang khusus untuk pasangan dengan karakter **lemah lembut, slow (tenang), dan penyayang**.

## Fitur Utama
- 💌 **Amplop Segel Lilin (Wax Seal Gate)**: Membuka hadiah secara bertahap dengan denting lonceng halus & konfeti kelopak bunga.
- 🎶 **Pemutar Musik Kotak Musik & Suara Hujan (Web Audio API)**: Musik lullaby akustik dan ambient hujan lembut yang menenangkan jiwa tanpa perlu khawatir tautan audio eksternal mati.
- 📜 **Surat Cinta Penuh Kelembutan**: Teks puitis yang menyentuh hati dan nama panggilan yang bisa diganti langsung.
- 🌸 **6 Kartu Apresiasi Kepribadian**: Mengulas tutur katanya yang santun, langkahnya yang tenang, pelukannya yang hangat, dsb.
- 🍯 **Toples Kata-Kata Manis (Affirmation Jar)**: Mengambil origami afirmasi penenang saat lelah atau sedih.
- 🎟️ **Kupon Kasih Sayang (Love Coupons)**: Kupon yang bisa ditukarkan di dunia nyata dengan cap tanggal otomatis.
- 🎁 **Kotak Hadiah & Piagam Cinta**: Sertifikat pasangan tersayang seumur hidup.
- 💬 **Sudut Catatan Berdua**: Tempat meninggalkan pesan balasan yang tersimpan di browser.
- 🧘‍♀️ **Ruang Napas Tenang**: Latihan pernapasan rileks (Inhale... Hold... Exhale...).

## Menjalankan Project
```bash
npm install
npm run dev
```
Akses di browser: `http://localhost:5173/`
